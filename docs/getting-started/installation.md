# Installation

**Audience:** developers  
**Status:** canonical

## PyPI

```bash
pip install balansis
```

## Extras

```bash
pip install balansis[plot]
pip install balansis[notebook]
pip install balansis[torch]
pip install balansis[all]
```

## Supported Python Versions

- Python 3.10
- Python 3.11
- Python 3.12

## Core Dependencies

- `pydantic >= 2.5`
- `numpy >= 1.24`

## From Source

```bash
git clone https://github.com/XTeam-Pro/Balansis.git
cd Balansis
poetry install
```
