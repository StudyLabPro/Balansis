# Core Concepts

**Audience:** developers and researchers  
**Status:** canonical

Balansis is easier to understand if you separate the mathematical vocabulary
from the Python API surface.

## Core Runtime Concepts

- **`AbsoluteValue`**: the signed-magnitude runtime object
- **`ABSOLUTE`**: the ACT additive identity
- **`EternalRatio`**: the structured ratio abstraction
- **compensation factor**: the explicit auxiliary signal returned by low-level
  compensated operations
- **Compensator**: the higher-level interface over low-level operations
