# Algebra Runtime Overview

**Audience:** developers and technically curious readers  
**Status:** canonical

The runtime algebra package currently exposes these main classes:

- `AbsoluteGroup`
- `EternityField`

These are Python runtime classes in `balansis.algebra`. They should be read as
implementation-level algebra helpers, not as replacements for the theorem
surface documented in `docs/formal/`.
