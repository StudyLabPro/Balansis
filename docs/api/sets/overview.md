# Sets Runtime Overview

**Audience:** developers and technical readers  
**Status:** canonical

The `balansis.sets` package contains set-oriented runtime helpers and
generators.

## Current Exports

- `EternalSet`
- `global_compensate`
- `verify_zero_sum`
- `harmonic_generator`
- `grandis_generator`

## Scope

This package is useful for runtime experimentation and stream-like compensation
patterns. It is not the same thing as the separate `tnsim/` repository
subproject, though the themes are related.
